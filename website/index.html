01 — The route

One path out.

WireSpot starts Windows Mobile Hotspot from the WireGuard connection itself. Windows shares the tunnel, not your normal connection, with every device that joins.

  1. 01

    Your laptop

    Wi-Fi, Ethernet or USB uplink

  2. 02

    WireGuard tunnel

    Your VPN profile, verified

  3. 03

    Mobile Hotspot

    Windows shares the tunnel

  4. 04

    Your devices

    Phone, tablet, console

Route around the VPN? The hotspot stops.

Fail-closed guard. WireSpot verifies the hotspot source and watches for a path around the VPN. If protection fails while it runs, the guard stops the hotspot.

04 — What it changes

Know what runs.

WireSpot changes real parts of Windows. Here is exactly what, and what it leaves behind.

  1. 01

    It runs as administrator.

    It creates a WireGuard tunnel service and starts Windows Mobile Hotspot. Its runtime VPN copy has administrator-only access.

  2. 02

    It cleans up after itself.

    When you disconnect or uninstall, it removes what it created. Uninstall asks whether to keep your settings and VPN profiles.

  3. 03

    It stays on your PC.

    Settings and profiles stay local. The hotspot password is stored in plain text in your local settings file, so use a unique one.

Before you install

  • Windows 10 or 11
  • WireGuard for Windows
  • A Wi-Fi adapter that supports Mobile Hotspot
  • Administrator access

Honest limits

Device approval is applied after a device's first packet, so there can be about a one-second window. A device that rejoins with a randomized MAC address asks again. Approval is enforced only while WireSpot runs.

05 — Get started

From install to online.

  1. 1

    Install WireGuard

    Install WireGuard for Windows. It provides the tunnel service WireSpot uses.

  2. 2

    Install WireSpot

    Run the installer, review what it changes, and choose your shortcuts and startup options.

  3. 3

    Import and go live

    Import a WireGuard .conf, set a hotspot name and password, then press Go live.

Your VPN profile

Get a Proton .conf in four steps.

You can bring a WireGuard profile from any compatible provider. This is the Proton VPN path.

  1. Sign in to Proton VPN, or create an account.Open the Proton VPN account site. WireSpot never asks for your account password.
  2. Go to Downloads → WireGuard configuration.Choose Windows as the platform, name the config, and pick the VPN options your plan offers.
  3. Choose a server in the country you want.Proton also offers a recommended server. Click Create, then Download to save the .conf file.
  4. Import it into WireSpot.Open Profiles → Import a .conf file, review the details, then choose Go live. Keep the file private: it contains a VPN key.

06 — Questions

Good to know.

Something else? Open an issue, but never post a VPN key or password.

Do I need Proton VPN?

WireSpot works with WireGuard profiles, including Proton VPN .conf files. You provide the VPN connection.

Can I use Ethernet or USB for my laptop's internet?

Yes. WireSpot detects the uplink from Windows routing. Your Wi-Fi radio still hosts Mobile Hotspot.

Does it send my VPN keys anywhere?

No. Configuration files stay on your PC. WireSpot checks its exit IP through ipify while connected. A speed test contacts Cloudflare only when you start it; it sends generated bytes, never your VPN keys.

Can I check a profile before connecting?

Yes. Check resolves and pings its server. Some servers ignore ping, so a missing response doesn't mean the VPN is broken. Once connected, WireSpot can verify a recent WireGuard handshake.

What happens if the VPN drops?

WireSpot checks the tunnel and hotspot route, and stops the hotspot if its guard detects a protection failure while WireSpot is running.

How do I uninstall it?

Use Settings → Uninstall WireSpot, or Apps & features. It first stops its own tunnel, hotspot and DNS lock, then removes the program. You choose whether to keep your settings and VPN profiles or delete everything.
